# 观星者纪元 · Stargazer Epoch

按 `GAME_DESIGN.md` 做出来的可玩原型。纯前端，无构建、无依赖。

## 怎么打开

双击 **`start.bat`**，会启动本地服务器并自动打开浏览器。

也可以手动：

```powershell
cd E:\ClickerGameProject
python -m http.server 8123
# 浏览器打开 http://localhost:8123/index.html
```

> 直接双击 `index.html` 也能跑，但部分浏览器会限制 `file://` 下的存档，推荐用上面的方式。

## 玩法

- **点击星图**：观测恒星，获得星尘。点击会点亮**点击位置周围**的星，不会再随机点亮别处的星。
- **范围点亮 / 弹射观测**：科技树左下角的分支。范围点亮让一次点击点亮周围一片；弹射观测让光从一颗星弹到另一颗，弹射次数与每次数量都能升级，两者相乘（弹射共振后为乘法叠加），点起来连锁很爽。
- **连击**：一秒内点击数越多倍率越高：5 次/秒 = ×2，20 次/秒 = ×10。科技可把满值线降到 15 次/秒；「恒星心律」解除上限。断连后每秒衰减，不会瞬间清零。科技树左下角三个节点（节拍器 / 肌肉记忆 / 恒星心跳）逐步放开上限与窗口。
- **五层视角**：星区 → 星座 → 旋臂 → 银河 → 宇宙。星区/星座层可观测（星座层一次记录整个星座的 12 个星区），旋臂以上只读，点一下会自动飞近。
- **点击成长**：10 级点击升级（倍率 + 秒产占比交替）。满级平点约 1 万颗、暴击约 10 万颗，叠满弹射后可达百万级——点击始终是有存在感的输出。
- **星尘**：购买 12 种观测设施。设施比早期版本弱一个数量级，主要作为稳定的底噪与里程碑来源。
- **星区完整记录**：产出研究点，用来研究科技树。
- **科技**：提升全局倍率、解锁设施、扩展视野。
- **视野**：决定星图能被点亮到多远；拖动星图，去点亮视野边缘。
- **里程碑 / 章节**：1 → 10²⁴，每个数量级都有演出和日志。
- **跃迁**：10¹¹ 颗后解锁（首次约 40 分钟），把进度压缩成星核，进入多元宇宙。
- **巨构**：戴森环、戴森球、环世界……建成后永久出现在星图上。
- **流星**：定时划过星图，点中可获得临时倍率。

操作：拖动平移，滚轮 / 双指缩放。连点不会触发镜头移动。缩小看星域，放大看每一颗；继续缩远可以看到整个星系与 2000 亿颗星的宇宙。

## 多元宇宙

首次跃迁后，HUD 会出现「宇宙 x / 10」。

- **闭合宇宙**：本宇宙观测满 300 亿颗即可闭合。获得 **+1 星核**、**宇宙常数 ×1.15**（永久全局倍率），并换上新的天空。
- **保留**：科技、视野、星核、收集；**清空**：设施、星尘、星区、点击升级、暗科技。
- **宇宙修正**：每个宇宙随机带一个**纯增益**——点击 ×3 / 设施 ×2 / 全局 ×1.5 / 研究 +50% / 流星 ×2 / 暴击 +8%。
- **大坍缩**：点亮 10 个宇宙后可大坍缩，获得大量星核、宇宙常数 ×2，下一轮要求 100 个宇宙，以此类推。
- 档案页可以看到宇宙进度、宇宙常数，以及「宇宙总量 2,000 亿颗 · 已观测 x%」。

## 暗科技 · 熄灭路线

观测数到 10¹³ 时会截获一段「异常信号」，选择拆解或上报，都能解锁**暗科技**（禁忌碎片 + 暗物质）。

- 左下角的 **熄灭模式** 开关（或科技页里的切换）：点击改为熄灭恒星，获得暗物质（数值是星尘的 5 倍），但已记录的恒星会从计数里消失。
- **宇宙反噬**：熄灭比例越高，全局产出越低（每 1% 约 -0.8%，寂静协议可减免 30%）。
- 10 个暗科技节点：熄灭理论 → 寂静协议 / 引力坍缩 / 暗能量提取 / 超新星诱导 / 因果断裂 / 黑洞引擎 / 真空衰变 / 熵减装置 → 归零协议。
- **真空衰变**：主动技能，瞬间熄灭视野内 5% 的恒星，冷却 5 分钟。
- **熵减装置**：把熄灭的恒星全部重燃，反噬回落。
- 禁忌碎片来源：异常信号、暗红流星（6% 概率）、「来自远方的警告」事件。

### 结局

| 结局 | 条件 |
|---|---|
| **门扉** | 观测 10²⁴ 且熄灭比例 < 10% |
| **归零**（隐藏） | 研究「归零协议」，熄灭比例 ≥ 99.5%，然后在最后抉择里「熄灭它」 |
| **最后一颗** | 同上，但选择「停下」 |
| **回声**（真结局） | 两种结局都完成后自动触发 |

## 本次实现的范围

已实现：

- Canvas 星图：确定性生成、圆形视野、迷雾、LOD（恒星 / 星区热力图 / 星系 / 宇宙）
- 12 种设施 + 数量里程碑、10 个点击/暴击升级
- 17 节点科技树（含 3 个跃迁门槛、范围点亮与弹射分支）
- 6 种恒星 + 脉冲星 / 黑洞特效
- 里程碑、章节、5 套背景、结局演出
- 跃迁、多元宇宙（闭合宇宙 / 大坍缩 / 纯增益修正）、星核商店、3 个可选流派
- 6 种巨构（带星图上的永久环）
- 暗科技 10 节点、熄灭模式、警告阶段、四种结局
- 流星（含暗红流星）、随机事件、抉择弹窗
- 收藏：成就、日志、收集加成
- 离线收益、本地存档（10 秒自动保存）
- 程序化音效 / 环境音乐（首次点击后启动）

数值与节奏（实测基准：每 2 秒点击一次、每 3 秒采购一次）：

| 里程碑 | 时间 |
|---|---|
| 50 颗 | ~0.1 分钟 |
| 1 万颗 | ~3.5 分钟 |
| 100 万颗 | ~10 分钟 |
| 1 亿颗 | ~19 分钟 |
| 10¹¹（首次跃迁） | ~43 分钟 |

相对 GDD 的取舍：

- 设施产出整体下调一个数量级，点击成为主要手感来源；视野倍率由 18/260/3000/25000/2e5 调整为 14/160/1600/12000/90000，避免一小时里反复「几秒一个数量级」。
- 10¹² 之后的视野节点需要先跃迁 1 / 2 / 3 次，形成真正的轮回。
- 第一次跃迁仍是 10¹¹；之后按「点亮 10 个宇宙」计数，而不是再攒一次 10¹¹。
- 微信登录 / 排行榜 / 广告未接入，留作下一阶段。
- 88 命名恒星、星云图鉴、皮肤等收集项目前是成就 + 日志的精简版。

## 开发备注

- 纯 JS + Canvas 2D，文件即模块，按 `index.html` 里的顺序加载。
- 逻辑层固定 10Hz tick，渲染 60FPS，二者分离。
- 调试面板：按 **`~`** 打开，可加星尘 / 研究点、切 ×10/×100 速度、跳视野。
- 存档键：`stargazer_epoch_save_v1`（localStorage）。
- 清档：浏览器控制台 `localStorage.removeItem('stargazer_epoch_save_v1'); location.reload()`。
